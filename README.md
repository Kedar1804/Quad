# QuadRide - Student Travel Partner App

QuadRide is a ride-sharing app designed specifically for college students. It enables students with vehicles to publish rides and allows others to find and book rides. By encouraging ride-sharing within college communities, QuadRide aims to make student commuting more convenient, cost-effective, and environmentally friendly.

## Features

- Publish Rides: Students with vehicles can post their rides, including details like date, time, destination, and amount.
- Find and Book Rides: Other students can browse available rides, view detailed information, and book rides directly through the app.
- Firebase Integration: Utilizes Firebase for user data management, real-time updates, and secure data storage.
- Ride Confirmation via Email: Upon booking, both the ride publisher and the rider receive a confirmation email.
- Safety and Security: Access is restricted to same-college students, fostering a secure and trusted environment.

## Tech Stack

- Android :(Java)
- Firebase :(Authentication, Firestore, and Cloud Functions)
- Cloud Functions: Used for backend email notifications.
- Figma: For creating user interface
